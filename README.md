# 建筑工程项目多智能体管理平台

本仓库现在是一个可运行的本地演示平台，而不是单一静态页面。当前推进策略调整为“项目层优先”：先把项目经理部的进度、质量、成本、安全、资料五条线闭环跑通，再接入公司级多项目总览。

## 目录结构

- `admin-web/`: 桌面管理端，当前默认进入项目层五条线管理
- `field-h5/`: 现场移动端，覆盖巡检录入、整改反馈、资料快查、项目问答
- `api/`: 原生 Node API 服务，负责项目数据、权限、资料、安全、消息、Agent 任务
- `worker-agent/`: 多 Agent 规则与摘要逻辑
- `tests/`: Node 内置测试

## 当前演示能力

- 项目层：仪表盘、进度导入、质量检查/复验、成本快照、资料上传、安全整改、常驻项目智能体对话窗口、Agent 中心
- 公司层：保留 API 与页面能力，后续作为项目层数据成熟后的汇总入口接入
- 现场 H5：安全巡检录入、整改闭环反馈、资料快查、项目问答
- Agent：同步问答、异步分析任务、模型路由配置、组织架构配置、工作流测试
- 建设规划：平台内置“建设规划”页，并通过 `/api/platform/blueprint` 输出阶段路线、接口契约、验收场景和默认假设
- 审计日志：资料上传/索引、进度导入、质量检查/复验、成本快照、安全巡检、整改反馈、Agent 任务全量留痕
- 模型网关：支持切换 `DeepSeek`、`OpenAI`、`Private LLM` 占位通道
- 权限：演示 `公司管理层`、`项目经理`、`现场安全员` 三类角色

## 本地运行

安装额外依赖不是必需的，直接使用 Node 内置能力即可：

```bash
npm start
```

默认地址：

```text
http://localhost:5180
```

入口页会提供两个链接：

- `/admin-web/`
- `/field-h5/`

## 测试

```bash
npm test
```

## 说明

- 当前数据为内置演示数据，重启服务后会重置
- 资料上传、进度导入、质量检查、成本快照和安全巡检会触发模拟 Agent 分析与站内通知
- 模型网关当前为可切换占位实现，便于后续接真实模型服务
- `docs/product-blueprint.md` 和 `docs/api-contract.md` 是后续工程化建设的基线文档
