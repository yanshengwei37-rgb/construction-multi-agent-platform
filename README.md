# 建筑工程项目多智能体管理平台

本仓库现在是一个可运行的本地演示平台，而不是单一静态页面。它包含公司层桌面端、项目层桌面端、现场 H5、内置 API、模型网关和 Agent Worker，方便直接演示多项目总览、项目下钻、资料接入、进度分析、安全整改和项目问答。

## 目录结构

- `admin-web/`: 桌面管理端，覆盖公司层总览与项目级模块
- `field-h5/`: 现场移动端，覆盖巡检录入、整改反馈、资料快查、项目问答
- `api/`: 原生 Node API 服务，负责项目数据、权限、资料、安全、消息、Agent 任务
- `worker-agent/`: 多 Agent 规则与摘要逻辑
- `tests/`: Node 内置测试

## 当前演示能力

- 公司层：多项目横向对比、排序看板、项目下钻
- 项目层：仪表盘、进度导入、资料上传、风险热力图、技术成本摘要、Agent 中心
- 现场 H5：安全巡检录入、整改闭环反馈、资料快查、项目问答
- Agent：同步问答与异步分析任务
- 审计日志：资料上传/索引、进度导入、安全巡检、整改反馈、Agent 任务全量留痕
- 模型网关：支持切换 `DeepSeek`、`OpenAI`、`Private LLM` 占位通道
- 权限：演示 `公司管理层`、`项目经理`、`现场安全员` 三类角色

## 本地运行

安装额外依赖不是必需的，直接使用 Node 内置能力即可：

```bash
npm start
```

默认地址：

```text
http://localhost:5180
```

入口页会提供两个链接：

- `/admin-web/`
- `/field-h5/`

## 测试

```bash
npm test
```

## 说明

- 当前数据为内置演示数据，重启服务后会重置
- 资料上传和进度导入会触发模拟 Agent 分析与站内通知
- 模型网关当前为可切换占位实现，便于后续接真实模型服务
